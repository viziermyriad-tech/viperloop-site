# VIPERLOOP 🐍

Неоновая 3D-змейка в стиле slither.io — теперь полноценное **PWA**: устанавливается в браузер и **работает офлайн**.

## Управление

| Действие | Клавиатура | Сенсорный экран |
|---|---|---|
| Поворот | ← → (или A / D) | Держать левую / правую часть экрана |
| Ускорение (сжигает длину) | ↑ / W / пробел / ЛКМ | Держать оба пальца |
| Звук вкл/выкл | M | Кнопка 🔊 в углу |

Змейка всегда ползёт сама. Ешь светящиеся сферы и дропы убитых (ценны больше), врезайся в чужие тела — жертва рассыпается сферами. Копей в чью-то голову — и ты рассыпался сам.

## Запуск

Открой `index.html` в браузере — этого достаточно (Three.js лежит локально в `vendor/`).

Для PWA нужны HTTPS (или localhost) и `sw.js` — например:

```bash
npx serve . -p 8080   # https-прокси обязателен для service worker
# или любой static-хостинг: GitHub Pages, Cloudflare Pages…
```

## Сборка

- `tools/make-icons.js` — перегенерирует иконки PWA (чистый Node, без зависимостей): `node tools/make-icons.js`
- Имя, манифест и цвета — `manifest.webmanifest`
- Обновления игры — `sw.js` (bump константы `CACHE` при смене версии)

## Структура

```
index.html             игра (Three.js) + PWA-регистрация
sw.js                  service worker: офлайн-кэш, network-first для навигации
manifest.webmanifest   манифест PWA
vendor/three.min.js    Three.js r128 (локальная копия)
icons/                 иконки PWA (192 / 512 / maskable / apple)
tools/make-icons.js    генератор иконок
```
